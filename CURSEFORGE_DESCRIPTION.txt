Shadowed Unit Frames - Worgen Fix

This is a SUF fix, not a new addon.

ShadowedUnitFrames-WorgenFix is an unofficial, minimally modified build of the original Shadowed Unit Frames v4.3.9-classic addon for WoW Classic Era and Hardcore.

Blizzard's Classic Era 1.15.8 API changes can cause the unmodified SUF release to stop while rendering target debuffs. As a result, debuff icons disappear below the target unit frame even though Blizzard nameplates still display them.

WorgenFix adds narrowly scoped compatibility fallbacks that restore target-frame debuff icons on Classic Era 1.15.8 and later, including 1.15.9.

The original SUF architecture, Lua identifiers, profiles, configuration, aura filters, and normal behavior are intentionally preserved wherever possible. This project does not introduce a new unit-frame system or a new feature set.

IMPORTANT: EXISTING SUF SETTINGS ARE NOT IMPORTED AUTOMATICALLY

WorgenFix uses a separate SavedVariables database to avoid modifying or mixing with the original addon's data. A fresh WorgenFix installation therefore starts with its own settings.

To reuse your existing SUF profiles and layouts, you must copy and rename the SavedVariables file manually while WoW is completely closed. Follow the manual migration instructions before starting the game:

https://github.com/worgenrage/ShadowedUnitFrames-WorgenFix#migrating-an-existing-suf-configuration

INSTALLATION

Both addon packages are required:

ShadowedUnitFrames-WorgenFix
ShadowedUF_Options-WorgenFix

Extract both folders into:

World of Warcraft/_classic_era_/Interface/AddOns/

The resulting file structure should include:

Interface/AddOns/ShadowedUnitFrames-WorgenFix/ShadowedUnitFrames-WorgenFix.toc
Interface/AddOns/ShadowedUF_Options-WorgenFix/ShadowedUF_Options-WorgenFix.toc

Do not rename either addon directory. Restart the WoW client completely after installation because /reload does not detect newly installed addon directories.

Open the addon configuration with:

/suf

SAVEDVARIABLES

WorgenFix uses a separate SavedVariables database named ShadowedUFDBWorgenFix. It does not automatically import, modify, or share the original addon's ShadowedUFDB database.

Existing SUF profiles can be migrated manually. Close WoW completely and follow the migration instructions available in the project README:

https://github.com/worgenrage/ShadowedUnitFrames-WorgenFix#migrating-an-existing-suf-configuration
